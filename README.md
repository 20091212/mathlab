# MathLab 数学计算器

一个 Windows 桌面数学工具：**科学计算 · 函数绘图 · 方程求解 · 矩阵运算 · 统计分析 · 单位换算**
全部中文界面、离线运行、无需联网，计算结果自动保存历史。

---

## 一、怎么用（两种方式）

| 方式 | 操作 | 说明 |
|---|---|---|
| **推荐** | 双击 `dist\MathLab.exe` | 单文件绿色版，不用装 Python，可拷到任何 Windows 电脑 |
| 备选 | 双击 `启动 MathLab.bat` | 用源码启动（本机已装 Python 时可用） |

打开后：左边是六个功能页，右边是历史记录面板，最下面是状态栏（会显示操作提示）。

---

## 二、六个功能页

**1. 计算器**
- 边打字边预览结果；回车即算。
- 自动给出**分数提示**（如 `1/3`）、**进制换算**（整数的十六/二/八进制）。
- 键盘按钮区点着用也行：`÷ × − + ^ √ π e x! 1/x x²`、`ANS`、记忆键 `M+ / MR / MC`。
- `↑` `↓` 可以翻出以前算过的表达式。

**2. 函数绘图**
- 最多同时画 **3 条曲线**（可单独勾选显示/隐藏，颜色自动区分）。
- 滚轮缩放、按住拖动平移、双击复位；勾掉「自动 Y 轴」可手动定范围。
- **求零点**：一次列出当前范围内所有与 x 轴的交点。
- **保存 PNG**：导出 2 倍超采样的清晰图片，可直接插进报告。

**3. 方程求解**（三合一）
- **一元二次/三次**：填 a、b、c（d 不填就解二次），给出根、判别式、顶点、对称轴、根之和/之积；无实根时给出共轭复根。
- **通用方程 f(x)=0**：直接写 `x^3 - 2x + 1 = 0` 或 `sin(x) - 0.5 = 0`，指定区间即可求根，并自动代回校验。
- **线性方程组**：按自然写法逐行输入，例如
  ```
  2x + y - z = 8
  -3x - y + 2z = -11
  -2x + y + 2z = -3
  ```
  自动识别未知数，给出唯一解 / 无解 / 无穷多解（含行简化阶梯形）。

**4. 矩阵运算**
- 输入 A、B（每行一行，元素用空格或逗号分隔）。
- 支持：`A±B`、`A×B`、`k·A`、转置 `Aᵀ`、行列式 `det(A)`、逆 `A⁻¹`、秩、`RREF`、迹、**特征值**（2×2 / 3×3 / 4×4，含复根）。

**5. 统计**
- 粘贴一串数据（逗号/空格/换行分隔），一次算出：个数、求和、均值、中位数、众数、最值、极差、总体/样本方差、总体/样本标准差、四分位数、四分位距、平方和。
- **线性回归**：填 X、Y 两行数据，得到 `y = a + b·x`、相关系数 r、R²，并可一键画到绘图页。

**6. 单位换算**
- 12 类：长度、面积、体积、质量、时间、速度、压强、能量、功率、角度、数据、温度。
- 左输右出实时换算；下方表格列出**该数值在同类所有单位下的结果**，双击任一行即可把它设为目标单位。
- 温度支持 °C / °F / K 互换。

```
四则运算   1+2*3    (1+2)*3    10/4    7//2(整除)    7%3(取模)

           comb(n,r) perm(n,r) gamma(n) mod(a,b)  |x-3|

```

## 四、快捷键

| 按键 | 作用 |
|---|---|
| `Enter` | 计算 |
| `↑` / `↓` | 翻历史表达式 |
| `Esc` | 清空输入框 |
| `Ctrl+1` ~ `Ctrl+6` | 切换功能页 |
| `Ctrl+H` | 显示 / 隐藏右侧历史面板 |
| `Ctrl+L` | 光标跳到当前页输入框 |
| `F5` | 重新计算 |
| `F1` | 帮助（同「帮助 F1」按钮） |
| 绘图区 | 滚轮缩放 · 拖动平移 · 双击复位 |

## 五、历史记录

- 每一次计算自动保存，位置：`%LOCALAPPDATA%\MathLab\history.json`
- 支持**搜索**、**★ 收藏**（「清空」时收藏项会保留）、右键菜单、**导出 CSV / TXT**。
- 双击一条记录即可回填到当前页的输入框。

## 六、文件结构

```
MathLab\
├─ dist\MathLab.exe       ← 成品（双击运行）
├─ 启动 MathLab.bat        ← 源码方式启动
├─ build_exe.bat           ← 重新打包成 exe 的脚本
├─ main.py                 ← 启动入口（含 --selftest 自检）
├─ make_icon.py            ← 生成图标
├─ test_engine.py          ← 数学内核测试（119 项）
├─ smoke_gui.py            ← 界面端到端测试（会截图到 out_shots\）
├─ assets\mathlab.ico      ← 图标
└─ mathlab\
   ├─ engine.py            ← 数学内核：表达式/方程/矩阵/统计/换算
   ├─ plot.py              ← 自绘函数绘图控件（含 PNG 导出）
   ├─ history.py           ← 历史存储
   └─ gui.py               ← 界面
```

---

## 七、维护

- **自检**：`python main.py --selftest check.json`（打包后的 exe 同样支持 `MathLab.exe --selftest check.json`），结果写进 JSON。
- **测试**：`python test_engine.py`（数学内核）、`python smoke_gui.py`（界面端到端 + 截图）。
- **重新打包**：双击 `build_exe.bat`（需已装 pyinstaller：`pip install pyinstaller`）。
- 想加新功能，改 `mathlab/engine.py`（算法）或 `mathlab/gui.py`（界面）即可，测试脚本可直接复用。
